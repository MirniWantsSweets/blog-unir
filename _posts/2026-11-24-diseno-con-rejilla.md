El diseño con rejilla divide la página en columnas y filas dentro de unos márgenes. Así los elementos quedan bien colocados y la página transmite orden y continuidad.

Bootstrap lo aplica con una rejilla de doce columnas y varios puntos de corte: móvil, tableta y escritorio. La misma página se reorganiza según el ancho disponible.

Hoy el CSS moderno permite hacerlo sin librerías gracias a CSS Grid, que añade o quita columnas según el espacio.

Un buen diseño adaptable también es accesible: el texto se puede ampliar, el contenido no se pierde en pantallas pequeñas y todo se puede usar con el teclado.
